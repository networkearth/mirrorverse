## Validated Tag Movement Data

Pop-up satellite tag data from Chinook salmon in the Gulf of Alaska will form the foundation of this study. Existing tag deployment data will be used, with fish originally captured by hook and line across multiple locations: Dutch Harbor, AK (n=20), Chignik, AK (n=16), Craig, AK (n=8), Homer, AK (n=20), Kodiak, AK (n=13), Yakutat, AK (n=16), Sitka, AK (n=15), and Central Bering Sea (n=3). Only healthy individuals meeting minimum size criteria (62-100cm fork length) were selected for tagging. Pop-up satellite archival tags were attached following established protocols, and tagged fish were released at their capture locations.

From these deployed tags, time-series depth, temperature, and position data will be collected once tags surface and transmit. The tags recorded temperature, ambient light intensity, and depth information at specified sub-day intervals during deployment—measurements that enable light-based geolocation with temperature-based corrections using surface temperature data. Each tag was programmed to release from the fish, surface, and transmit collected data over satellite. Data were transmitted in time-series format with measurements at 2.5-15 minute intervals before uploading.

With raw tag transmissions in hand, the next step will convert these data to spatially-gridded position estimates at H3 resolution 4. To obtain location estimates, the data from each tag will be passed through a proprietary hidden Markov model from Wildlife Computers that uses the tag's data to estimate likely paths taken by the fish during deployment (Wildlife Computers, 2025). An estimate of location for each day will then be derived as the central tendency of those paths on that particular day. Position estimates will be converted to the Uber H3 hierarchical hexagonal grid at resolution 4 (~26km edge length hexagons). Aggregation to this resolution accommodates geolocation uncertainty while maintaining meaningful spatial resolution, creating spatially-standardized movement tracks.

Once standardized position estimates are obtained, the dataset will be filtered to retain only post-acclimation movement data. Fish behavior immediately following tagging may reflect handling stress rather than natural movement. All movement data from the first seven days post-deployment will therefore be excluded from analysis, allowing fish time to return to normal behavioral patterns.

This acclimation-filtered dataset will then undergo screening to remove post-mortality records. Constant depth readings (no variation in pressure measurements) indicate mortality with the tag either on the seafloor or at the surface. Temperature stabilizing at internal body temperature of known salmon predators, differing from ambient water temperature, indicates predation mortality. Michael Courtney and Andrew Seitz will identify which predator body temperatures to use based on their previous Chinook salmon mortality research. Each fish's track will be scanned to identify the mortality transition point based on these indicators, and all data following detected mortality will be excluded. Removing post-mortality data prevents confounding stationary dead fish with behavioral patterns.

The resulting validated trajectories will then be visualized and data retention summarized across filtering steps. A map showing all validated movement trajectories will demonstrate geospatial coverage across the Gulf of Alaska. A summary table will report data retention: total tags deployed, tags recovered, data points before and after the acclimation filter, and data points before and after the mortality filter. Individual-level statistics showing the distribution of track durations and data point counts per fish will demonstrate spatial extent of the data and quantify the impact of quality control steps.

## Migration Classification and Filtering

Chinook salmon undergo distinct migration periods (Beamish, 2018) that must not be confounded with the movement patterns enabling identification of distribution preferences. A model distinguishing between migrating and non-migrating fish across the dataset will therefore be developed.

Training data for this classifier will first require expert assembly. Michael Courtney and Andrew Seitz will identify unambiguous migration periods and unambiguous non-migration periods through manual expert labeling, as no standard methodology exists for this classification. Clear positive and negative examples will establish the training foundation, while the classifier will be able to handle ambiguous intermediate cases.

Example trajectories with classified migration and non-migration segments will then be visualized to validate the labeling approach. Map examples will show trajectories with migration segments (red) and non-migration segments (blue) overlaid. Examples will be selected to illustrate the range of movement patterns observed in classified data, demonstrating that the classification successfully distinguishes migration patterns in geospatial context.

From this labeled dataset, temporal movement features will be derived using bidirectional time windows. Temporal windows will examine both forward and backward in time from each point of interest. Window sizes will be constrained to one week or less to help retain data from fish with shorter tagging periods. Features will be extracted from movement data only (no environmental features), as migration should be identifiable from the nature of the movement alone. Feature types will include momentum (sustained directional movement), behavioral consistency (erratic versus steady patterns), and temporal continuity (persistence across window).

With features computed, a supervised classifier will be trained to predict migration periods. The model will predict migration probability given features from the bidirectional temporal window. Model performance will be evaluated by first identifying an operating point at which false negatives (falsely labeled migration points) are expected to be below 5% on the validation dataset, and then evaluating the true negative rate (correctly labeled non-migration points). The higher the true negative rate, the better, as it means a large number of non-migration samples can be retained without accidentally polluting the dataset with migration samples. Class balancing will be applied to ensure equal representation of migration and non-migration periods during training. Candidate models will include random forests, XGBoost, and neural networks, with other architectures considered if issues arise.

Classifier performance will be documented through standard evaluation metrics. A confusion matrix showing true and false positives and negatives on the validation set will be generated. ROC curves for both training and testing sets will assess generalization and identify potential overfitting.

The trained classifier will then be applied to isolate non-migratory movements from the full dataset. All unlabeled time points will be classified using the selected operating point. Points classified as migration will be removed from the dataset. The resulting dataset will contain only non-migration movements for movement model training—a dataset where migration movements have been filtered out with high confidence.

Results of this filtering will be summarized in a table reporting total time points, points classified as migration, and points classified as non-migration. Individual-level statistics will show the distribution of migration periods per fish.

## Feature-Enriched Training Data

A comprehensive list of candidate environmental features that could inform movement modeling will be developed and categorized. An exhaustive feature list will be compiled from published literature and expert panel input (Andrew Seitz, Michael Courtney, Curry Cunningham) to ensure consideration of features beyond those typically used. Features will be categorized as: stationary (bathymetry), temporal (temperature), or stateful (productivity/chlorophyll). Such features will be pulled from ocean models such as Copernicus Marine Service. All features will be standardized to Uber H3 resolution 4 and daily temporal resolution for joining with movement data.

With this exhaustive feature set assembled, vector embedding analysis will cluster features by information content. Dimensionality reduction techniques are normally used to ensure highly correlated features are not included in the same model, helping prevent overfitting. Vector embeddings take advantage of neural networks to learn non-linear relationships between features, as opposed to techniques like PCA that require linear relationships. This technique will reduce the exhaustive feature set into a set of lower cardinality, allowing the feature space to be explored more quickly and robustly. The resulting derivative features may have little physical meaning, however. To restore parsimony, a subset of the original exhaustive feature set that are themselves predictive of the embedded features will be identified. These representative features will then become the candidates for modeling.

Representative features will then be normalized and scaled for neural network compatibility. Neural networks require normalizing feature ranges to avoid biasing gradient descent toward specific features. Features will be rescaled to [0,1] if non-negative (representing scales or magnitudes) or [-1,1] if containing negative values, keeping all features in similar ranges to ensure similar gradient magnitudes across features during optimization.

The movement data will then be resampled to ensure balance across space, time, and individual fish. The study area will be divided into four spatial regions: Aleutian Island Chain, Kodiak to Yakutat, Southeast Alaska (to British Columbia border), and British Columbia and south. These spatial regions correspond with typical fisheries management boundaries in the Gulf of Alaska. Each spatial region will be further divided into seasonal blocks (Winter, Spring, Summer, Fall), as Chinook behavior varies seasonally (Gietzmann-Sanders, in review; Seitz, 2024) and finer temporal resolution would spread data too thinly. Samples will be collected into each space-time block with equal representation across all blocks. Within each block, data from each individual will be resampled with replacement to ensure all individuals in each area and time are equally represented.

From this balanced dataset, examples will be created from observations and joined to features to create the final training dataset. First, the 90th percentile range of movement per day per fish will be calculated. Then examples from each movement will be created that include: origin location, actual destination, and all potential destinations (H3 resolution 4 cells) within the 90th percentile daily range to capture realistic movement options. The actual destination will be labeled as "selected." These positions and times will then be joined to their corresponding features as described above.

## Movement Probability Model

Movement modeling will be posed as a classification problem, predicting where a fish will go given the features at potential destinations (including staying in place). Classification models of this type provide likelihoods of selecting any specific class—in this case, likelihoods of the various destinations. This allows the model to build a transition matrix indicating how density at any point in the grid will move in the next timestep, which is exactly what density tracking requires.

A log-odds modeling framework will be used to predict these movement choices. The large number of potential movement choices, each associated with its own features, creates a very high-dimensional feature space. This presents a challenge because the volume of data required to fit a model effectively can grow exponentially with feature space dimensionality (Verleysen, 2005). By using a log-odds modeling framework, the effective feature space dimensionality reduces to the number of features per option rather than features across all options (Gietzmann-Sanders, in review). This greatly increases the odds of fitting models without overfitting. The MIMIC framework (Gietzmann-Sanders, in review) will be used as it provides an implementation for log-odds models.

As the first step, input data will be reorganized in preparation for training. The data will be split into training, testing, and validation sets, with individuals assigned to only one set (no fish split across sets) to prevent data leakage from autocorrelated movements within individuals across testing and training sets. Contrast resampling (Gietzmann-Sanders, in review) will then be employed as it is a requirement for log-odds modeling. If high biases toward specific regions or times are observed in any of the datasets after this step, the earlier unbiasing may be skipped and applied at this point instead.

Models will then be trained and hyperparameter-tuned across the feature set. Hyperparameter tuning will be driven by performance over the validation set in order to hold out the testing set until the very end. Performance will be measured by the negative log likelihood of the data given model predictions. The model that performs best over the validation set will be selected.

Feature predictivity will be assessed by training models with incrementally added features. Starting with a null model (no features), the most predictive feature will be added (identified by fitting with only that feature and evaluating over the validation dataset). Features will continue to be added until arriving at the selected model. This incremental addition approach quantifies how much predictive power each feature contributes beyond those already included. Building from single features upward reveals which features can predict movement independently versus those that only contribute in combination with others. Each incremental model will then be evaluated across the held-out test set for final assessment. The most predictive of these will be selected for subsequent analyses.

Performance metrics across selected and incremental models will be summarized. A performance table will compare predictive accuracy across the incremental models. Metrics will include training, validation, and testing set performance for the selected model to demonstrate generalization and absence of overfitting.

Relationships between environmental features, observed movements, and model predictions will then be visualized. Plots will show how predicted movement probabilities vary with key environmental features, validating that model behavior matches ecological expectations. Comparisons of predicted versus observed movement patterns across feature gradients will demonstrate that the model captures realistic environmental responses. These visualizations will identify where predictions align with or diverge from observations, building confidence in model predictions and revealing potential limitations.

## Bycatch Risk Maps

Gulf of Alaska pollock fleet catch data will be processed and standardized for risk modeling. Bycatch will be binned to Uber H3 resolution 4 and daily temporal resolution to match the movement model's spatiotemporal scale. Two standardization approaches will be applied: by effort alone (standard CPUE), and by effort weighted by depth-occupancy likelihood to incorporate additional information about vertical distribution. Depth weighting accounts for pollock trawls occurring primarily near the seafloor (De Robertis, 2006), where predicted Chinook depth occupancy affects encounter probability. From this, two datasets will be created—a binary catch/no-catch dataset to test whether relative risk of any bycatch can be predicted, and a normalized catch quantity dataset to test whether bycatch levels can be differentiated.

Bycatch data coverage and characteristics will be summarized across space and time. A summary table will show the number of fishing events, spatial coverage, and temporal coverage. Maps will show the distribution of bycatch events across the Gulf of Alaska. These summaries will demonstrate data availability for training the risk model and identify coverage gaps that may limit prediction reliability in certain regions or time periods.

With bycatch data prepared, movement probability matrices will be generated and attractor indices derived for bycatch locations. This density tracking reveals basins of attraction in the Gulf. Model features will be computed across the entire Gulf of Alaska for trawl data time periods plus and minus one month to enable rolling window analysis. These model features will predict transition matrices per day. For each time point in the bycatch data, the analysis will move back one week and start with a uniform initial distribution. That distribution will be propagated forward using the transition matrices, revealing likely areas of fish accumulation. The resulting density per H3 cell represents an "attractor index," with higher values indicating areas more likely to attract fish. This process will be repeated for two, three, and four weeks prior to assess performance across different time horizons (week to month), with flexibility to adjust windows based on findings. In the end, each trawl event will be paired with attractor indices derived from one-, two-, three-, and four-week time windows.

Training data will be constructed from paired fishing events compared on bycatch outcomes. Given that attractor indices only have meaning relative to nearby H3 cells, fishing events that are reasonably close in space and time will be paired (constrained by data availability). Equal representation of three categories will be ensured: both have bycatch, only one has bycatch, and neither has bycatch. This prevents the model from defaulting to always predicting risk differences and ensures its ability to identify when risk levels are actually similar, supporting reliable decision-making. These pairs will then be divided into training, validation, and testing sets.

A decision tree will be trained to predict relative bycatch risk using attractor-derived features. The problem will be set up as predicting which of each given pair is the better choice (results in less bycatch) given only information about the pair's attractor indices. Decision trees will be used for extreme parsimony, enabling full explanation of the decision-making process with attractor index features; alternative models will be considered if predictive performance is insufficient. The loss function will be the expected bycatch given the probabilities the model assigns to each decision. Minimizing this loss function will create a decision tree that minimizes expected bycatch over the training samples. The validation set will be used to explore features, model structures, and hyperparameters.

Bycatch risk model performance will be evaluated on held-out testing data. Performance metrics will compare predictions to observed bycatch on the testing set. Results will be reported relative to a 50/50 random baseline, representing the paired comparison null hypothesis where the model cannot discriminate between locations. This will demonstrate whether the model provides meaningful risk predictions beyond chance.

Finally, interpretable spatial risk maps will be generated for specific time periods. Given that the model effectively generates pairwise distances (difference in assigned probabilities) for all cells, these distances can be used for clustering. Agglomerative clustering will group cells with similar risk levels using the distance matrix, with flexibility to explore alternative distance-based clustering methods if needed. Clusters will be assigned colors to create discrete risk zones (minimally green, yellow, and red for low, medium, and high risk) that are immediately interpretable for decision-making. These visualizations will demonstrate the spatial structure of bycatch risk as predicted from movement patterns.
