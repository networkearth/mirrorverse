# Instructions
Given the specified directory look for `Rationale.md` which will contain content for an introduction section for a proposal. Your job is to write out introduction prose in the same directory in the file `Introduction.md`. 

An introduction should be posed as a funnel starting from a need/perspective that is axiomatic and working step by step down to the goal of the study. The content in `Rationale.md` is split into two levels. Level 1 are the topic sentences. Each paragraph in the introduction should capture one step in our funnel. These topic sentences will capture those steps. Level 2 are development sentences which fill out the step introduced by the topic. As such each section should be in Lead/Development form. To better understand how the format of `Rationale.md` fits into this paradigm see `Format of Content` below. 

# Narrative Flow
When composing the introduction, focus on creating smooth narrative flow between and within paragraphs:

**Between paragraphs:**
- Each paragraph should naturally set up the next. The end of one paragraph should create a question or tension that the next paragraph addresses.
- Avoid mechanical transition words like "However," "That being said," or "While" at the start of paragraphs. Instead, let the logical progression carry the reader forward.
- When introducing a new concept, briefly connect it to what came before rather than announcing it abruptly.

**Within paragraphs:**
- Development sentences should flow as connected prose, not as a list of facts strung together with periods.
- Use varied sentence structures—mix longer explanatory sentences with shorter emphatic ones.
- When presenting multiple examples or data points, weave them together with phrases that show their relationship (e.g., "Similarly," "This pattern extends to," "The same trend appears in").

**Avoid these common problems:**
- Starting consecutive sentences with the same structure
- Restating what was just said before adding new information
- Abrupt topic shifts that leave the reader wondering "why are we talking about this now?"
- Ending paragraphs without momentum toward the next idea

# Format of Content
The content will be formatted as:

```markdown
**Lead:** Topic sentence for the first paragraph.
**Development:**
- First development sentence for the first paragraph
- Second development sentence for the first paragraph

**Lead:** Topic sentence for the second paragraph.
**Development:**
- First development sentence for the second paragraph
- Second development sentence for the second paragraph
```
