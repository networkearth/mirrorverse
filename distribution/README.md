# Instructions for Using Prompts

1. Even after a review everything may make no sense. You _have_ to go back through content to make sure the logic and order make sense and that there isn't loads and loads of redundancy (LLM's have a habit of being really redundant).
2. Use these prompts to create workflows with the agent! Workflows are way more useful and flexible than just expecting the agent to dump one big monolithic poo. (The RecipeComposition.md is a great example of this.)
